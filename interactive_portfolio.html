Interactive Game Portfolio

Transforming the recruitment experience into an immersive Unity-based exploration.

Project Overview

Built an interactive game-style portfolio where players explore a virtual world, access terminals to learn about my background, projects, and certifications, and connect to my social platforms through an engaging experience.

Key Features

Immersive Virtual World: Designed a 2D environment that serves as a living representation of my skills and creative vision.

Interactive Terminals: Players can interact with in-game terminals to trigger information pop-ups and link directly to project repositories.

Cross-Platform Connection: Integrated direct links to LinkedIn, GitHub, and professional portfolios through the game interface.

Technical Breakdown

Developed using Unity and C#, this project utilizes raycasting for interaction, complex UI canvas management, and custom shaders to maintain a consistent high-tech aesthetic.
