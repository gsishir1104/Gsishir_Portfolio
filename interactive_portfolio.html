Interactive Game Portfolio

My implementation

I built a Unity portfolio that visitors explore as a 2D character. In-game computer terminals open panels for projects, certifications, contact details, and background information.

Movement and animation integration

In PlayerController2D, keyboard and mobile input set the Rigidbody2D horizontal velocity. A Physics2D.OverlapCircle ground check gates jumping. The script updates Unity Animator parameters isGrounded, isWalking, and yVelocity, connecting animation state to movement and ground contact.

This describes animation integration in code; it does not claim that I authored the animation clips or measured an improvement in input latency.

Terminal interaction

2D trigger callbacks track the nearby terminal. Pressing E calls ToggleComputer(). The terminal sets its Animator’s IsActive parameter, waits for a configurable activation delay, and opens the assigned UI manager. An isActivating guard prevents repeated toggles during a transition.

The closing coroutine waits for the relevant panel to close before resetting the terminal animation and restoring its prompt. This sequencing coordinates the UI and terminal animation; interaction uses trigger colliders rather than raycasting.
