Flappy Bird JavaFX Clone

Project Overview: This JavaFX implementation faithfully recreates the popular mobile game Flappy Bird. The project demonstrates object-oriented programming principles, game physics implementation, and UI design using Java's graphics libraries.

Key Features:

  • Physics-Based Gameplay: Implemented realistic gravity, jump mechanics, and collision detection
  • Procedural Level Generation: Created an algorithm that generates pipes at varying heights
  • Score Tracking System: Developed a scoring system that increments when passing through pipes
  • Game State Management: Designed state system for different game phases (start, playing, game over)
  • Responsive Controls: Implemented keyboard controls with precise timing for jump mechanics

Technical Implementation:

The game uses JavaFX for rendering with the AnimationTimer class providing smooth 60fps gameplay. The physics system uses kinematic equations to simulate gravity and velocity.

// Core game loop using JavaFX AnimationTimer private void updateGame() { // Apply gravity only after the game has started if (gameStarted && !gameOver) { // Add initial positive velocity to prevent instant falling if (velocityY == 0) { velocityY = 2; // Start with small downward velocity } // Apply gravity and update position velocityY += gravity; bird.y += velocityY; // Update pipes and check for collisions ArrayList<Pipe> newPipes = new ArrayList<>(); for (Pipe pipe : pipes) { pipe.x += pipeSpeed; // Score when passing through pipes if (!pipe.passed && bird.x > pipe.x + pipe.width) { score += 0.5; pipe.passed = true; } // Check for collisions if (collision(bird, pipe)) { gameOver = true; highestScore = Math.max(highestScore, score); } // Keep pipes that are still visible if (pipe.x + pipe.width > 0) { newPipes.add(pipe); } } pipes = newPipes; // Check if bird is out of bounds if (bird.y > HEIGHT || bird.y < 0) { gameOver = true; } // Generate new pipes when needed if (pipes.isEmpty() || pipes.get(pipes.size() - 1).x < WIDTH / 2) { placePipes(); } } } // Collision detection method private boolean collision(Bird bird, Pipe pipe) { return bird.x < pipe.x + pipe.width && bird.x + bird.width > pipe.x && bird.y < pipe.y + pipe.height && bird.y + bird.height > pipe.y; }

Development Challenges:

Implementing collision detection was a significant challenge since JavaFX doesn't have built-in physics. I created custom collision logic using bounding boxes and coordinate calculations.

Optimizing pipe generation involved creating a pool of pipe objects that are reused as they move off-screen, reducing garbage collection overhead.
