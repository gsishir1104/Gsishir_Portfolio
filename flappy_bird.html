Flappy Bird JavaFX

A faithful recreation demonstrating OOP principles and custom physics implementation.

Project Overview

This implementation utilizes Java's graphics libraries to demonstrate game physics and UI design. The game uses JavaFX AnimationTimer to provide smooth 60fps gameplay.

Key Features
Physics-Based GameplayImplemented realistic gravity, jump mechanics, and collision detection.
Procedural GenerationCreated an algorithm that generates pipes at varying heights dynamically.
Game State ManagementDesigned a system for start, playing, and game-over phases.
Responsive ControlsPrecise keyboard timing for jump mechanics.
Core Game Loop & Physics 
// Apply gravity and update position
velocityY += gravity;
bird.y += velocityY;

// Collision detection logic
private boolean collision(Bird bird, Pipe pipe) {
    return bird.x < pipe.x + pipe.width && 
           bird.x + bird.width > pipe.x &&
           bird.y < pipe.y + pipe.height && 
           bird.y + bird.height > pipe.y;
}
Development Challenges

Custom Physics: Since JavaFX lacks a built-in physics engine, I developed custom collision logic using bounding boxes and coordinate calculations.

Optimization: I implemented object pooling for pipe generation to reuse objects as they move off-screen, significantly reducing garbage collection overhead.
