Flappy Bird JavaFX

My implementation

I built the game loop, input handling, pipe generation, collision detection, scoring, and restart flow in JavaFX. The implementation uses separate Bird and Pipe objects and draws them on a Canvas.

Concrete implementation details

  • Movement: AnimationTimer.handle() calls the update and draw methods while the game is active. Each update increases vertical velocity by gravity and adds that velocity to the bird’s position. Space sets upward velocity to -9 during play.
  • Obstacles: placePipes() creates top and bottom pipes at a randomized vertical offset with a gap of HEIGHT / 4. Pipes move left by four pixels per update. Off-screen pipes are removed from the active list.
  • Collision: collision() compares the bird and pipe rectangles on both axes. An overlap sets gameOver; going above or below the play area also ends the run.
  • Scoring and restart: A passed flag prevents repeated scoring for the same pipe. Each pipe contributes half a point. Reset clears pipes and score, resets position and velocity, and returns to the start state.

Tradeoffs

The current implementation creates pipe objects rather than pooling them. Movement is measured per update rather than elapsed time, so consistent speed across different frame rates is a future improvement. No FPS or garbage-collection improvement is claimed.
