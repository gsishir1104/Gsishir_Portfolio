Flappy Bird JavaFX Clone

Project Overview: This is a faithful recreation of the popular mobile game Flappy Bird, built entirely with Java and JavaFX. The project demonstrates object-oriented programming principles, game physics implementation, and user interface design using Java's graphics libraries.

Key Features:

  • Physics-Based Gameplay: Implemented realistic gravity, jump mechanics, and collision detection to mirror the original game's feel.
  • Procedural Level Generation: Created an algorithm that generates pipes at varying heights with consistent gaps for the player to navigate through.
  • Score Tracking System: Developed a scoring system that increments each time the player successfully passes through a pair of pipes.
  • Game State Management: Designed a state system to handle different game phases (start, playing, game over) with smooth transitions.
  • Responsive Controls: Implemented keyboard and mouse controls with precise timing for the jump mechanic.

Technical Implementation:

The game was built using Java and JavaFX for rendering. The core game loop runs on the JavaFX AnimationTimer class, providing smooth 60fps gameplay. The physics system uses simple kinematic equations to simulate gravity and velocity.

// Core game loop
public void startGame() {
    AnimationTimer timer = new AnimationTimer() {
        @Override
        public void handle(long now) {
            if (gameState == GameState.PLAYING) {
                updateBirdPosition();
                updatePipes();
                checkCollisions();
                updateScore();
                renderGame();
            }
        }
    };
    timer.start();
}

// Bird physics implementation
private void updateBirdPosition() {
    birdVelocity += GRAVITY;
    bird.setY(bird.getY() + birdVelocity);
    
    // Rotate bird based on velocity
    if (birdVelocity < 0) {
        bird.setRotate(-25); // Point upward when ascending
    } else {
        bird.setRotate(Math.min(90, bird.getRotate() + 2)); // Rotate downward when falling
    }
}

Development Challenges:

One of the main challenges was implementing the collision detection between the bird and the pipes. Since JavaFX doesn't have built-in physics collision, I had to create custom collision detection using bounding boxes and coordinate calculations.

Another challenge was optimizing the pipe generation and removal to maintain performance. The solution involved creating a pool of pipe objects that are reused as they move off-screen, reducing garbage collection overhead.
