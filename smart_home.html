Voice Controlled Home Appliances

Innovative smart home system utilizing Embedded C, NodeMCU, and voice recognition to bridge the gap between software commands and high-voltage hardware.

Key Features
Voice RecognitionProcesses spoken commands in real-time with custom recognition logic.
Hardware InterfaceSafely controls high-voltage appliances via relay modules.
Wireless ConnectivityIntegrated Bluetooth for remote execution from smartphones.
Safety & MonitoringReal-time energy tracking and fail-safe overload protection.
Hardware Implementation

Utilized a NodeMCU microcontroller connected to a relay module. GPIO5 (D1) controls the bulb, while GPIO2 (D4) interfaces with the fan system.

Command Processing Logic (Embedded C) 
void processVoiceCommand(char* command) {
    toLowercase(command); // Case-insensitive matching
    
    if (strstr(command, "light on")) {
        controlAppliance(LIGHT, ON);
    } 
    else if (strstr(command, "fan on")) {
        controlAppliance(FAN, ON);
    }
    // Safety check occurs before relay activation
}
Development Challenges

Noise Cancellation: Implemented adaptive algorithms to filter ambient sound for reliable recognition in noisy environments.

Electrical Safety: Integrated opto-isolators and real-time current monitoring to safely manage AC power sources.
