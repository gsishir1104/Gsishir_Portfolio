Phantom Escape: Enchanted Maze

Project overview

A third-person Unity game focused on exploring a maze, solving puzzles, and avoiding enemies. I used an existing Unity template as the starting point and wrote code for teleportation, player movement, player detection, and the minimap.

My Technical Contributions

  • Teleportation: Wrote the code for the game's teleportation mechanic.
  • Player movement: Wrote the code that controls player movement.
  • Player detection: Wrote the game's player-detection logic.
  • Minimap: Wrote the code for the minimap feature.

Template features

The enemy patrol and pursuit behavior came from the existing Unity template. I used those systems rather than writing them from scratch.
