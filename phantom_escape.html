PHANTOM ESCAPE: ENCHANTED MAZE

Captivating third-person puzzle-maze game developed in Unity.

Project Overview

The core gameplay revolves around navigating a mysterious maze, solving puzzles, and evading intelligent AI enemies.

Key Features
  • Advanced AI Enemy Patrols Implemented sophisticated AI behaviors including patrol paths, line-of-sight detection, and pursuit logic.
  • Seamless Animation Transitions Designed smooth animation transitions for the player and enemies, enhancing responsiveness.
  • Immersive Atmospheric Visuals Crafted using Unity's HDRP pipeline with custom shaders for magical effects and dynamic lighting.
  • Optimized Performance Utilized occlusion culling and state machine architecture to maintain high FPS in complex environments.
Development Insights

By implementing a state machine architecture combined with spatial partitioning, we achieved realistic enemy behaviors and optimal game performance. The lighting system dynamically adjusts based on player location, enhancing discovery.
