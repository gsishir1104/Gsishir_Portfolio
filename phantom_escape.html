Phantom Escape: Enchanted Maze

Project Overview: Phantom Escape: Enchanted Maze is a captivating third-person puzzle-maze game developed in Unity. The core gameplay revolves around navigating a mysterious maze, solving puzzles, and evading intelligent AI enemies.

Key Features:

  • Advanced AI Enemy Patrols: Sophisticated AI behaviors with patrol paths, line-of-sight, and pursuit logic.
  • Seamless Animation Transitions: Smooth transitions for characters and enemies.
  • Immersive Atmospheric Visuals: Lighting, textures, and particles for an eerie vibe.
  • Intuitive Puzzle Mechanics: Logical and interactive puzzles.
  • Responsive Third-Person Controls: Fluid and responsive control system.

Technologies Used:

  • Game Engine: Unity
  • Programming Language: C#
  • Tools: Blender (for models), Visual Studio

Learning Outcomes:

  • Developed complex AI behaviors
  • Managed animation states
  • Optimized game performance
  • Designed puzzle mechanics
  • Completed full development pipeline
