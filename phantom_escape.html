Phantom Escape: Enchanted Maze

Project Overview: Phantom Escape: Enchanted Maze is a captivating third-person puzzle-maze game developed in Unity. The core gameplay revolves around navigating a mysterious maze, solving puzzles, and evading intelligent AI enemies.

Key Features:

  • Advanced AI Enemy Patrols: Implemented sophisticated AI behaviors for enemies, including patrol paths, line-of-sight detection, and pursuit logic, creating a challenging and dynamic environment.
  • Seamless Animation Transitions: Designed and integrated smooth animation transitions for the player character and enemies, enhancing visual fluidity and responsiveness.
  • Immersive Atmospheric Visuals: Crafted a visually stunning environment with carefully chosen lighting, textures, and particle effects to create an enchanting yet eerie atmosphere.
  • Dynamic Puzzle Mechanics: Developed interactive puzzle elements that respond to player actions, creating an evolving gameplay experience.
  • Optimized Performance: Implemented efficient rendering techniques and occlusion culling for smooth performance across various hardware.

Development Insights:

The development of Phantom Escape presented unique challenges in creating believable enemy AI that could navigate the complex maze environment while maintaining performance. By implementing a state machine architecture combined with spatial partitioning, we achieved both realistic enemy behaviors and optimal game performance.

The atmospheric visuals were crafted using Unity's HDRP pipeline, with custom shaders developed for the magical effects seen throughout the maze. The lighting system dynamically adjusts based on player location, enhancing the sense of mystery and discovery.
