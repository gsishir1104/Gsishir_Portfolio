Voice Controlled Home Appliances

Project Overview: This innovative smart home system allows users to control household appliances using voice commands. Built with Embedded C, this project demonstrates practical IoT implementation, hardware interfacing, and voice recognition technologies.

Key Features:

  • Voice Command Recognition: Implemented a custom voice recognition system that processes spoken commands in real-time.
  • Appliance Control Interface: Designed circuitry to safely control high-voltage appliances through relay modules.
  • Wireless Communication: Integrated Bluetooth connectivity for remote command execution from smartphones.
  • Energy Monitoring: Added power consumption tracking for each connected appliance.
  • Safety Protocols: Implemented fail-safes and overload protection to ensure user safety.

Hardware Implementation:

The system uses a NodeMCU microcontroller connected to a relay module to control appliances. The wiring configuration is as follows:

  • Power Connection: NodeMCU VIN (5V) pin → Relay Module VCC
  • Ground Connection: NodeMCU GND pin → Relay Module GND
  • Bulb Control: NodeMCU GPIO5 (D1) pin → Relay Module Input 2
  • Fan Control: NodeMCU GPIO2 (D4) pin → Relay Module Input 1
  • Appliance Wiring: COM pin connected to live wire, NO pin connected to appliance
  • Power Source: All appliances connected to AC power source through relay module

// Process voice command and control appliances void processVoiceCommand(char* command) { // Convert command to lowercase for case-insensitive matching toLowercase(command); // Command recognition logic if (strstr(command, "light on")) { controlAppliance(LIGHT, ON); sendResponse("Turning lights on"); } else if (strstr(command, "light off")) { controlAppliance(LIGHT, OFF); sendResponse("Turning lights off"); } else if (strstr(command, "fan on")) { controlAppliance(FAN, ON); sendResponse("Turning fan on"); } else if (strstr(command, "fan off")) { controlAppliance(FAN, OFF); sendResponse("Turning fan off"); } else { sendResponse("Command not recognized"); } } // Control appliance through relay void controlAppliance(Appliance device, State state) { // Safety check before activating relay if (safetyCheck(device)) { if (state == ON) { setRelay(device, HIGH); logActivity(device, ON); } else { setRelay(device, LOW); logActivity(device, OFF); } } else { sendResponse("Safety check failed"); } }

Development Challenges:

The main challenge was creating a reliable voice recognition system that could work in noisy home environments. This was solved by implementing adaptive noise cancellation algorithms that dynamically filter background noise based on ambient sound analysis.

Another significant challenge was ensuring electrical safety when controlling high-voltage appliances. The solution involved implementing opto-isolators, fail-safe relay circuits, and real-time current monitoring to prevent overloads.
