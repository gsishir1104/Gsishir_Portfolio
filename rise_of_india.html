Unity Strategy Game

Rise of India

Blending historical education with turn-based strategy logic
Project Overview

The primary mission of this project is to allow players to explore and understand the vast History of India through interactive gameplay. By combining historical milestones with structured mechanics like turn-based decision-making and hero card strategies, the game transforms traditional learning into an engaging, playable experience.

Key Features
Narrative IntegrationDesigned to guide players through significant historical eras and milestones.
Hero Card StrategyDynamic system where Hero cards provide tactical advantages based on historical figures.
Turn-Based StructureRobust turn-management handling player transitions and real-time scoring.
Educational UIThematic interface that visually communicates data while maintaining a game-like aesthetic.
Development Insights

I addressed the challenge of balancing data and fun by utilizing a modular C# architecture, allowing for the addition of events without disrupting the core loop. I built the turn structure using a State Machine in Unity to ensure animations and educational prompts remain perfectly synchronized.
